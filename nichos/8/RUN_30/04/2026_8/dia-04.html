O template do Reel que explica “o motivo real” das marcas

Use este roteiro para dissecar decisões visíveis (patrocínio, collab, rebrand, aquisição) com a tese “não é só X, é Y” + prova de escala + tradução para benefício + pergunta A/B/C.

Hook com pergunta Autoridade em 1 frase Myth-busting Números/escala Benefício prático CTA guiado

Resumo

Objetivo

O que você vai gravar: um Reel que pega um “movimento” de uma marca e revela o mecanismo estratégico por trás (o que parece branding, mas também empurra conversão/retenção).

Promessa
“O motivo real por trás de X (e como isso vira vantagem)”
Tese central
“Não é só [explicação óbvia]. É [alavanca real].”
Quando usar: notícia quente, decisão pública (patrocínio, naming rights, collab), “mudança estranha” no produto/preço, nova parceria, campanha que todo mundo comentou.

Estrutura

7 blocos
  1. Hook (0–2s): pergunta específica (marca + movimento).
  2. Autoridade + contexto (2–5s): credencial em 1 frase + “isso explodiu essa semana”.
  3. Quebra de crença (5–10s): “Não é sobre X”.
  4. 3 camadas (10–35s): o que é / como funciona / por que dá vantagem.
  5. Prova de escala (35–45s): número, frequência, comparação, alcance.
  6. Tradução pro público (45–55s): “o que muda pra você?” (benefícios reais).
  7. Fecho participativo (55–65s): pergunta + opções A/B/C.

Roteiro

Copiável
ROTEIRO (60–75s) — TEMPLATE

[B1 — HOOK | 0–2s]
“Por que a [MARCA] fez [MOVIMENTO GRANDE] agora?”

[B2 — AUTORIDADE + CONTEXTO | 2–5s]
“Eu sou [SUA FUNÇÃO] e, no marketing, não se fala em outra coisa: [MOVIMENTO] da [MARCA].”

[B3 — QUEBRA DE CRENÇA (MYTH-BUSTING) | 5–10s]
“E não: isso não significa [EXPLICAÇÃO ÓBVIA/INGÊNUA].”
“Na prática, é sobre [MECANISMO REAL EM 1 FRASE].”

[B4 — EXPLICAÇÃO EM 3 CAMADAS | 10–35s]
Camada 1 (o que é): “Isso é [DEFINIÇÃO SIMPLES, 1 FRASE].”
Camada 2 (como funciona): “Funciona assim: [CENA/IMAGEM MENTAL] + [EXEMPLO CONHECIDO].”
Camada 3 (por que dá vantagem): “O ganho real é: (1) [BENEFÍCIO 1], (2) [BENEFÍCIO 2], (3) [BENEFÍCIO 3].”

[B5 — PROVA/ESCALA | 35–45s]
“E repara na escala: [NÚMERO/COMPARAÇÃO/FREQUÊNCIA]. Isso muda completamente o jogo de percepção.”

[B6 — TRADUÇÃO PARA O CONSUMIDOR | 45–55s]
“Tá, e o que muda pra você? [PRÉ-VENDA | ACESSO | EXPERIÊNCIA | STATUS | ECONOMIA].”
“Ou seja: não é ‘marketing bonito’. É [EFEITO PRÁTICO NA ESCOLHA/RECORRÊNCIA].”

[B7 — FECHO PARTICIPATIVO | 55–65s]
“Faz sentido? Você acha que a [MARCA] deveria ir de: A) [OPÇÃO 1] / B) [OPÇÃO 2] / C) [OPÇÃO 3]?”
“Comenta A, B ou C — e me diz o porquê em uma frase.”

LEGENDA (modelo)
Tese: “Não é só [X]. É [Y].”
1 linha de contexto + 3 bullets de benefício.
Pergunta final A/B/C.

COMENTÁRIO FIXADO
“Voto rápido: A / B / C (sem textão).”

Dica de execução: fale em frases curtas e coloque micro-ganchos a cada 5–8s (“o ponto é…”, “repara nisso…”, “o pulo do gato…”).

Elementos visuais

Edição
  • Jump cuts a cada 1–2 frases.
  • Texto na tela com 1 ideia por vez (máx. 5 palavras).
  • Reforço na virada “NÃO É SÓ X / É Y” (zoom leve + texto grande).
  • Inserções (1–2): print da notícia, logo, ícone de “ingresso”, “fila”, “cartão”, “benefícios”.
  • Escala visual: números grandes (ex.: “100 mil”, “30 shows”, “+X milhões”).
Regra de clareza: definição → exemplo → benefício (nessa ordem). Não empilhe conceitos.

Copy e ganchos

Banco de frases

Hooks prontos (0–2s):

  • “Por que a [Marca] fez [movimento] justamente agora?”
  • “O que ninguém te contou sobre [movimento] da [Marca].”
  • “Não é sobre [óbvio]. É sobre [real].”

Micro-ganchos (a cada 5–8s):

  • “Repara nisso…”
  • “O pulo do gato é…”
  • “Na prática, o efeito é…”
  • “E aqui está o detalhe que muda tudo…”

Frases de myth-busting:

  • “Muita gente acha que é só [X]. Mas isso só é a casca.”
  • “Não significa que [interpretação rasa]. Significa que [mecanismo].”
  • “O objetivo não é ‘aparecer’. É virar preferência.”

CTA

Baixa fricção
  • Comentário guiado: “A, B ou C? Vote e justifique em 1 frase.”
  • Debate: “Isso é branding ou performance disfarçada? Por quê?”
  • Salvamento: “Salva pra usar esse raciocínio quando analisar patrocínios/parcerias.”
  • Direcionamento: “Quer que eu analise a sua marca? Diz seu nicho + objetivo.”
Comentário fixado recomendado: “Vota rápido: A / B / C (sem textão).”

Checklist

Criação

Pré-roteiro

  • [ ] Escolhi um movimento recente (notícia/decisão visível).
  • [ ] Escrevi a tese central: “não é só X, é Y”.
  • [ ] Separei 1 dado de escala (número/frequência/alcance).
  • [ ] Tenho 1 exemplo familiar (analogia) pra explicar sem jargão.
  • [ ] Listei 3 benefícios (percepção → comportamento → negócio).

Roteiro (60–75s)

  • [ ] Hook em pergunta com marca + ação.
  • [ ] Autoridade em 1 frase (sem aula).
  • [ ] Quebra de crença clara (“não é só…”).
  • [ ] 3 camadas (o que é / como / por que).
  • [ ] Tradução pro consumidor (“o que muda pra você”).
  • [ ] Fecho com A/B/C para comentário.

Edição e publicação

  • [ ] Jump cuts a cada 1–2 frases.
  • [ ] Texto na tela com palavras-chave (≤ 5 palavras).
  • [ ] 1–2 inserts (print/ícone/B-roll) para concretizar.
  • [ ] Legenda com tese + 3 bullets + pergunta final.
  • [ ] Comentário fixado com “A/B/C”.

Variações

Para escalar
  • Variação 1 (Preço): “Por que a [Marca] aumentou o preço? Não é ganância. É [posicionamento/margem/segmentação].”
  • Variação 2 (Collab): “Por que [Marca A] se juntou com [Marca B]? Não é hype. É [transferência de confiança/distribuição].”
  • Variação 3 (Influencers): “Por que contratar [perfil específico]? Não é alcance. É [associação/credibilidade/prova social].”
  • Variação 4 (Rebrand): “Por que mudar identidade? Não é estética. É [clareza de categoria/novo público].”
  • Variação 5 (Patrocínio): “Não é logo na camisa. É [acesso a momentos + benefícios + hábito].”
Troca rápida de tema: mantenha a mesma estrutura e só substitua (Marca + Movimento + Tese + Prova + Benefícios + A/B/C).
