Marketing explicado pra uma criança (e você aprende de verdade)

Post original: https://www.instagram.com/p/DH4MRIBvOna/
Abrir post

Resumo

Template replicável
Ideia central

Ensinar 1 conceito usando uma cena cotidiana com personagens + conflito. Você guia a audiência por dor → desejo → objeção e fecha com um payoff (“isso é X”).

Por que funciona

Promessa de simplicidade + humor/encenação + exemplo concreto + mini-framework aplicável + progressão (falha → diagnóstico → solução → resultado).

Tempo recomendado

35–55s (falha inicial até 5–7s; diagnóstico 10–15s; aplicação 12–18s; payoff 3–6s).

Melhor para

Storytelling, oferta, posicionamento, proposta de valor, objeções, prova, preço, diferenciação, CTA, funil, branding.

Parâmetros (preencha e grave)

Inputs
  • Conceito que você vai ensinar: [ex.: posicionamento]
  • Situação cotidiana: [ex.: pedir aumento / pedir sorvete]
  • Personagens: A quer algo / B decide
  • Negação (falha rápida): “Não.”
  • Dor do decisor/público: [o que ele quer evitar]
  • Desejo do decisor/público: [o que ele quer alcançar]
  • Objeção principal: [o medo/risco]

Estrutura (sequência reproduzível)

Passo a passo
  1. Hook (0–2s): promessa de clareza + curiosidade (“explicando como se você tivesse 8 anos”).
  2. Cena-problema (2–7s): tentativa errada + “não” imediato.
  3. Diagnóstico guiado (7–20s): 3 perguntas curtas → dor, desejo, objeção.
  4. Aplicação (20–40s): reescreva o “pedido” como micro-história usando os 3 itens (show, don’t tell).
  5. Payoff (40–48s): o decisor cede / conversão acontece.
  6. Carimbo final (48–55s): “Isso é [conceito]!” + CTA.
Regra de ouro do ritmo

Sem silêncio entre falas: cada frase empurra pra próxima etapa. Corte por frase/pergunta (jump cuts) e destaque palavras-chave na legenda.

Substituições rápidas (mesmo impacto)

[PERSONAGEM A/B]: filho/mãe • vendedor/cliente • candidato/recrutador • gestor/time • médico/paciente • aluno/professor.
[OBJETIVO]: aumentar preço • fechar proposta • pedir indicação • reter cliente • aprovar orçamento.
[AÇÃO/PROVA]: dado • print • caso real • demonstração • teste grátis.

Banco de frases para a micro-história

Dor: “Você já tá cansado de…” • “O que mais te atrasa é…”
Desejo: “O que você quer é…” • “Você só quer…”
Objeção: “E faz sentido ter medo de…” • “Eu também pensei…”

Elementos visuais (edição + tela)

High retention
Edição
  • Jump cut a cada frase/pergunta (cadência de “entrevista”).
  • Zoom-in leve nas palavras: dor, desejo, objeção e no “Isso é…”.
  • SFX discreto (pop/whoosh) ao mudar de etapa (opcional).
  • Personagens com mudança clara (boné/óculos/posicionamento esquerda/direita).

Variações (para outros temas sem perder o punch)

Adaptações
Variação 1 — “Consultoria relâmpago”

Em vez de “criança de 8 anos”, use: “Vou explicar como se eu fosse seu consultor por 30s”. Mantém autoridade + velocidade. Estrutura idêntica: falha → 3 perguntas → reescrita → payoff.

Variação 2 — “Antes vs Depois”

Mostre 2 versões do pedido: Antes (genérico) e Depois (com dor/desejo/objeção). Menos atuação, mais didático. Fecha com: “Viu? Não é sobre falar bonito, é sobre acertar a mensagem.”

Variação 3 — Troque o framework (mesmo formato)

Se o tema pedir, substitua “dor/desejo/objeção” por:
• Problema → Causa → Próximo passo (educativo)
• Contexto → Conflito → Resolução (storytelling puro)
• Promessa → Prova → Como começar (venda/autoridade)
Mantenha: falha inicial + perguntas guiadas + reescrita + payoff.

Variação 4 — Personagem “cliente difícil”

O “B” vira alguém com objeção forte (“Sem orçamento”, “Já tentei”). Você vence com história + prova. Ótimo pra: preço, diferenciação, consultoria, serviços premium.
