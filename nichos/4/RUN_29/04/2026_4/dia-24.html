Carrossel reproduzível: “Isso é X / Isso é Y” (contraste A vs B)

Modelo para educar rápido com comparação imediata: mesma headline em todos os slides + situações diferentes + 1 slide de prova + fechamento com X/✓ e CTA de 1 palavra.

Resumo

Alta retenção por repetição com variação

Ideia central: o carrossel cria um choque de percepção ao separar “o que parece” de “o que é de verdade”. Cada slide tem duas cenas (topo e base) para o cérebro comparar em 1 segundo.

Quando usar: para desmontar confusões comuns (ex.: faturar vs lucrar, crescer vs crescer com margem, vender vs ter caixa), ou qualquer tema com “ilusão” e “realidade”.

Meta de slides
7–9
Texto por slide
≤ 10 palavras
Prova obrigatória
1 slide com número/KPI
Regra de ouro: a headline quase não muda. Quem muda é a situação (cena), para escalar produção sem perder impacto.

Estrutura

Macro + micro replicável

Macro (sequência):

  • 1) Hook com padrão repetível (A/B) + contraste forte.
  • 2–4) Repetição com variações (cenários do dia a dia da audiência).
  • 5) Prova/Diagnóstico com número, KPI, gráfico, print (pode ser borrado).
  • 6) Virada: “o que muda” (processo/critério/rotina).
  • 7) Síntese com ❌ vs ✅ + CTA de 1 palavra.

Micro (por slide):

  • Faixa superior: “ISSO É [X]” (o que parece/ilusão).
  • Cena A: símbolo do erro (comportamento, ambiente, resultado).
  • Faixa inferior: “ISSO É [Y]” (o que é de verdade).
  • Cena B: símbolo do acerto (processo, critério, prova).

Slides sugeridos (1..9)

Exemplo em Finanças & Negócios (adaptável)

Tema exemplo: Faturar ≠ Lucrar (você pode trocar por qualquer par de conceitos com contraste).

Slide 1 — Hook:

Topo: ISSO É FATURAR
Base: ISSO É TER LUCRO
Cena A (topo): notificações de vendas/PIX, euforia, “muito entrando”.
Cena B (base): DRE simples, margem, caixa, calma.

Slide 2 — Realidade do dia a dia:

Topo: ISSO É FATURAR
Base: ISSO É TER LUCRO
Cena A: entrega correndo, retrabalho, desconto toda hora.
Cena B: preço defendido + processo + poucas urgências.

Slide 3 — Custo oculto:

Topo: ISSO É FATURAR
Base: ISSO É TER LUCRO
Cena A: fim do mês “cadê o dinheiro?” + boletos.
Cena B: provisões feitas + metas de margem.

Slide 4 — Erro que parece esperteza:

Topo: ISSO É FATURAR
Base: ISSO É TER LUCRO
Cena A: “crescer” com promoções e taxa de cartão comendo.
Cena B: unit economics acompanhados (CAC, CMV, margem).

Slide 5 — Prova/Diagnóstico (obrigatório):

Topo: ISSO É FATURAR
Base: ISSO É TER LUCRO
Cena A: gráfico de receita subindo.
Cena B: gráfico de margem caindo / caixa negativo.
Texto pequeno (opcional): Receita ≠ Resultado.

Slide 6 — A virada (o que muda):

Topo: ISSO É FATURAR
Base: ISSO É TER LUCRO
Cena A: decisões no "feeling".
Cena B: rotina semanal: DRE, caixa, preço, metas.

Slide 7 — Identidade / aspiração realista:

Topo: ISSO É FATURAR
Base: ISSO É TER LUCRO
Cena A: agenda lotada + urgência.
Cena B: agenda organizada + foco no que dá margem.

Slide 8 — Síntese com critério:

Título: A diferença não é sorte. É MÉTODO.
❌ Aumentar receita sem saber custos e margem.
✅ Crescer com precificação + controle de despesas + caixa.

Slide 9 — CTA (1 palavra):

Quer o checklist + modelo de DRE simplificado?
Comente: MARGEM
Trocas rápidas: substitua “FATURAR/LUCRO” por qualquer par: VENDER/TER CAIXA, CRESCER/CRESCER COM MARGEM, INVESTIR/INVESTIR COM MÉTODO, TRABALHAR/PRODUZIR RESULTADO.

SLIDES (7–9)
1) HOOK — contraste máximo
   Cena A (X): [situação comum + emoção]
   Cena B (Y): [situação madura + clareza]

2) VARIAÇÃO #1 — cotidiano da audiência
   Cena A: [microerro repetido]
   Cena B: [microacerto equivalente]

3) VARIAÇÃO #2 — custo oculto
   Cena A: [consequência: stress, retrabalho, dívida, volatilidade]
   Cena B: [benefício: paz, previsibilidade, foco]

4) VARIAÇÃO #3 — erro que “parece certo”
   Cena A: [atalho, gambiarra, desconto, urgência]
   Cena B: [critério, regra, processo]

5) PROVA / DIAGNÓSTICO
   Mostrar: [número/KPI antes vs depois | gráfico | print editado]
   Nota: se sensível, use valor fictício ou borrado.

6) VIRADA (o que muda)
   X acontece quando: [falta de rotina/critério]
   Y acontece quando: [processo semanal simples]

7) IDENTIDADE
   Cena aspiracional realista: [hábitos, planilha, calendário, reunião, KPI]

8) SÍNTESE (X/✓)
   Tese: "A diferença não é sorte. É [PROCESSO]."
   ❌ [erro 1]
   ✅ [prática 1]
   (opcional) ❌ [erro 2]
   (opcional) ✅ [prática 2]

9) CTA
   "Comente [PALAVRA] que eu te envio [recurso]."

Elementos visuais

Look limpo + prova ancorada
  • Layout fixo: duas faixas (topo/base) + 2 cenas por slide (A e B).
  • Contraste: em A use ruído/pressa/caos; em B use foco/claridade/ordem.
  • Prova: inclua 1 slide com KPI/gráfico/print (mesmo que fictício/borrado).
  • Textos curtos: headline em CAIXA ALTA; evite parágrafos dentro do slide.
  • Âncora de cor: destaque 1 palavra por slide (ex.: MARGEM, CAIXA, MÉTODO).
Substituições sem perder impacto: ilustração → foto; foto → mockup; mockup → ícones + gráfico simples. O essencial é comparação imediata + prova.

Copy e ganchos

Frases prontas + padrões

Padrões de título (capa):

  • “Isso é [X] / Isso é [Y]”
  • “Parece [X]. Na prática é [Y].”
  • “Você acha que é [X]. O jogo de verdade é [Y].”

Textos curtos (legenda) — escolha 1:

Opção 1 (tese direta)
A diferença entre [resultado ruim] e [resultado bom] não é sorte.
É [método/processo].

Opção 2 (dor + virada)
Se você [sintoma], não é falta de esforço.
É falta de critério.

Opção 3 (prova)
Receita alta sem margem vira trabalho + ansiedade.
Margem + caixa viram liberdade de decisão.

Ganchos para o primeiro comentário/pinned:

  • “Qual desses você está vivendo hoje: X ou Y?”
  • “Quer que eu te mande o modelo que eu uso? Comenta a palavra do CTA.”
  • “Se isso te deu um estalo, salva — você vai precisar revisar no fim do mês.”

CTA

1 palavra, rastreável, fácil

Regra: CTA de uma palavra + recompensa específica.

  • “Comente MARGEM que eu envio o checklist.”
  • “Comente CAIXA que eu mando o modelo de controle semanal.”
  • “Comente PREÇO para receber a planilha de precificação.”
  • “Me chama no DM com DIAGNÓSTICO que eu te mando as perguntas.”
Dica de performance: a recompensa deve ser “plugável” (checklist, template, modelo, perguntas). Isso aumenta comentários sem parecer genérico.

Variações (mesmo impacto, outros temas)

Substituições prontas

1) Variação por pilar (sem mudar o formato):

  • Mito vs Verdade: “Isso parece [X]. Isso é [Y].”
  • Erro comum: “Isso é [erro]. Isso é [correção].”
  • Passo a passo: “Isso é improviso. Isso é método (passo 1..3 no slide final).”
  • Objeção: “Isso é ‘não tenho tempo’. Isso é prioridade (1 ajuste prático).”

2) Pares de contraste (copiar e usar):

  • “Isso é vender / Isso é ter caixa”
  • “Isso é crescer / Isso é crescer com margem”
  • “Isso é reduzir custo / Isso é aumentar eficiência”
  • “Isso é trabalhar muito / Isso é produzir resultado”
  • “Isso é investir / Isso é investir com plano”

3) Trocas de cena (sem perder a lógica):

  • Se não tiver prints reais: use dashboards fictícios (valores redondos) + legenda “exemplo”.
  • Se não quiser aparecer: use mãos, tela, mesa, caderno, ícones e gráficos.
  • Se o tema for sensível: use blur + “dados ilustrativos”.
Identidade visual sugerida: fundo escuro, cards com borda suave, destaques em degradê (verde/azul/laranja), layout limpo e high-tech.
