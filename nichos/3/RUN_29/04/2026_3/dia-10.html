Combinações básicas + inesperadas que elevam seu look

Reel curto, acelerado e fácil de salvar: você valida o clássico (“funciona”) e entrega o upgrade (“mas com…”). Use 6–10 combinações em rajadas, com texto grande na tela.

Duração: 12–20s (até 25s)
Cadência: 1,5–2,5s por combo
Estrutura: repetição + virada
Objetivo: saves + comentários
Dica UX: grave apontando para o vazio e sobreponha as combinações como lista (alto contraste).

Resumo

O que executar
  • Abra com 1 combinação (sem introdução).
  • Repita o padrão: “X com Y funciona… mas com Z fica [benefício]” por 6–10 vezes.
  • Varie entre combinações seguras (clássicas) e a virada (inesperadas).
  • Finalize com pergunta de comunidade + pedido de save/parte 2.
Por que funciona: baixo atrito cognitivo + previsibilidade com novidade (o “mas…”) + linguagem emocional (identidade, não só técnica).

Estrutura

Template fixo
  1. Hook (1–2s): já comece em uma frase (combo pronto).
  2. Bloco repetido (6–10x): Seguro → “mas…” → benefício.
  3. Fecho (1–2s): pergunta + CTA (comentário/salvar/parte 2).
Fórmula de frase
[Base] com [Seguro] funciona. Mas com [Inesperado] fica [benefício].
Banco de benefícios (use 1 por combo)
eleva • refina • atualiza • ilumina • dá ponto de cor traz textura • fica moderno sem esforço • fica criativo sem exagero sofisticado • leve • marcante • elegante

Ajuste os elementos (cores/estampas/peças) para o seu público. Mantenha a estrutura e o ritmo.

Elementos visuais

Edição & tela
  • Texto on-screen: Linha 1 “X + Y” / Linha 2 menor “mas X + Z”.
  • Punch-in/zoom leve no “mas…” (momento de virada).
  • Cortes rápidos a cada combo (jump cuts).
  • Visual: você troca peças/acessórios; ou mostra paleta/looks em B-roll.
  • Som: música contínua + voz clara (ou “tap/click” sutil marcando trocas).
Padrão vencedor: previsibilidade (lista) + surpresa (virada) + adjetivo emocional.

Legenda (modelo)
Combinações simples que deixam o look mais interessante 👇 A regra é: valida o clássico e testa a virada. “X com Y funciona… mas com Z fica MUITO melhor.” Qual você vai usar primeiro? Comenta 1 número (1–8) e eu te mando uma sugestão extra pra essa cor/peça. Salva pra consultar na hora de se vestir. #consultoriadeimagem #combinaçãodecores #looks

CTA

Escolha 1 principal
  • Comentário: “Qual combinação você vai testar primeiro?”
  • Save: “Salva pra usar na próxima semana.”
  • Parte 2: “Quer parte 2 pra looks de trabalho/casual/festa?”
  • Personalização: “Me diz uma cor que você usa muito que eu te dou 3 combinações.”
Dica: na tela final, mostre “Comenta + Salva” em texto grande por 0,8–1,2s.

Checklist

Criação rápida
Pré-roteiro
  • [ ] Escolher 1 tema: cores | estampas | neutros | acessórios | trabalho | casual | festa
  • [ ] Listar 6–10 elementos base (cores/peças/estampas)
  • [ ] Para cada base, criar: 1 combo seguro + 1 combo “mas…”
  • [ ] Separar 8–12 benefícios/adjetivos (sofisticado, leve, marcante…)
Gravação & edição
  • [ ] Abrir com combo direto (sem “oi gente”)
  • [ ] Entonação sobe no “mas…” (surpresa)
  • [ ] 1,5–2,5s por combo + corte a cada frase
  • [ ] Texto grande, alto contraste, sempre no mesmo lugar
  • [ ] Punch-in/flash sutil no “mas…”
  • [ ] Tela final com CTA + pergunta

✓ Critério de qualidade: dá pra entender sem áudio só lendo a tela.

Variações

Para repetir o formato
Variação A — Neutros “anti sem graça”
“Bege com branco funciona. Mas bege com verde oliva fica moderno.” “Cinza com preto é elegante. Mas cinza com rosa antigo fica chique.” “Marrom com caramelo é seguro. Mas marrom com azul claro fica sofisticado.”
Variação B — Trabalho (arrumada sem esforço)
“Alfaiataria com branco é clássico. Mas com azul claro fica leve.” “Blazer preto funciona. Mas com tricô claro traz textura.” “Camisa lisa é certeira. Mas com lenço estampado eleva.”
Variação C — Acessórios (upgrade rápido)
“Look neutro funciona. Mas com brinco statement fica marcante.” “All black é seguro. Mas com cinto metalizado atualiza.” “Jeans com camiseta é básico. Mas com tênis colorido dá ponto de cor.”
Variação D — Estampas (sem medo)
“Listras com jeans é fácil. Mas listras com animal print fica fashion.” “Poá com preto é clássico. Mas poá com vermelho fica poderoso.” “Xadrez com neutros funciona. Mas xadrez com verde traz modernidade.”
