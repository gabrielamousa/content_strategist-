Identifique seu tipo de olheira (e o que funciona em cada uma)

Modelo reproduzível: diagnóstico simples → categorias → conduta prática → limite honesto → CTA de salvamento/seguidores.

Resumo

  • Promessa: ajudar a pessoa a se identificar em um tipo de [queixa] e entender o que costuma funcionar em cada caso.
  • Por que performa: gera autoidentificação ("é meu caso"), é fácil de salvar e reduz frustração com a frase-chave: "nem tudo resolve com cosmético".
  • Estratégia: repetição de padrão visual + rótulos claros + microchecklist por categoria.
Use com qualquer tema de Estética: acne (tipos), manchas (tipos), poros (causas), queda capilar (padrões), celulite (graus), flacidez (origens), melasma (padrões), rosácea (gatilhos).

Estrutura (reproduzível)

Diagnóstico → Ação → Limite → CTA
  1. Slide 1 (Capa): promessa + tema + credencial (autoridade) + microgancho.
  2. Slides 2–5 (Categorias): 1 tipo por slide com o mesmo bloco: como parece → quando piora → o que ajuda → erro comum/alerta.
  3. Slide 6 (Limites): quando cosmético/rotina não resolve + sinais de alerta + próxima ação segura.
  4. Slide 7 (Resumo rápido) – opcional: “Se é X, tende a ser Y” em formato checklist.
  5. Slide 8 (CTA): pedir salvar + seguir + pergunta para comentários (coleta de temas).

Slides sugeridos (1..8)

Modelo de 8 slides
  1. Capa: “Como identificar seu tipo de [QUEIXA] (por [CREDENCIAL])” + “e o que fazer em cada caso”.
  2. Tipo 1: [NOME DO TIPO] — sinais + gatilhos + condutas.
  3. Tipo 2: [NOME DO TIPO] — sinais + gatilhos + condutas.
  4. Tipo 3: [NOME DO TIPO] — sinais + gatilhos + condutas.
  5. Tipo 4 / Mistos: combinação + como priorizar a estratégia.
  6. Limites: “Quando [produto/rotina] não resolve” + “procure avaliação”.
  7. Checklist: 4 bullets de identificação rápida.
  8. CTA: salvar + seguir + comentar o próximo tema.

Elementos visuais (UX e design)

High-tech + clean

Layout por slide (padrão)

  • Topo: Título grande do tipo (ex.: “Vascular”, “Pigmentar”, “Inflamatório”).
  • Centro: faixa com 1–3 imagens (exemplo visual/recorte/ilustração).
  • Abaixo: 2–4 linhas de diagnóstico (como parece + quando piora).
  • Rodapé: “O que ajuda:” em bullets curtos (ativos/condutas).
  • Assinatura discreta: @ e credencial (consistência).

Diretrizes rápidas

  • Repetição: o mesmo template em todos os slides de categoria.
  • Contraste: texto sempre legível; evite sobrepor em fotos sem overlay.
  • Prova visual: use exemplos reais (com consentimento) ou diagrama/ilustração.
  • Slide “limite”: destaque com uma tarja/label para gerar atenção e credibilidade.

Copy e ganchos (substituíveis)

Alto impacto

Ganchos de capa

  • “Você não tem um tipo de [queixa]. Você pode ter 4.”
  • “Antes de tratar [queixa], identifique isto (evita gastar errado).”
  • “Guia rápido: qual é o seu tipo de [queixa]?”
  • “O que funciona para [tipo A] não é o melhor para [tipo B].”

Frases de retenção (slides 2–6)

  • “Se piora com [gatilho], presta atenção nesse tipo.”
  • “Esse é o tipo que costuma confundir com [tipo X].”
  • “Aqui vai o erro que mais atrasa resultado: [erro].”
  • Realismo (credibilidade): “Em alguns casos, cosmético sozinho não dá conta.”

CTA (modelos prontos)

Escolha 1 + 1
  • Conversão (seguir): “Me siga para mais guias práticos de [pele/corpo/cabelos] com embasamento.”
  • Salvar: “Salve este post para consultar quando for montar sua rotina.”
  • Comentário: “Comente ‘GUIA’ que eu faço a versão de [tema].”
  • Pesquisa de pauta: “Qual queixa você quer que eu ‘classifique’ no próximo carrossel?”

Variações (mesmo impacto, outro tema)

Substituições inteligentes
  • Troque “tipos” por “causas”: “Por que seu [problema] acontece (4 causas comuns) e o que fazer”.
  • Troque “categorias” por “níveis/estágios”: “Grau 1–4 de [celulite/flacidez] e abordagem em cada um”.
  • Troque “produtos indicados” por “hábitos indicados” (para conteúdo mais amplo e menos dependente de marcas).
  • Slide 6 alternativo (Objeção): “Por que você não vê resultado com [ativo] (3 motivos)”.
  • CTA alternativo (captura): “Comente ‘LISTA’ para eu te mandar os ativos por tipo” (use DM/automação).
  • Modelo para temas comuns:
    • Acne: comedonal / inflamatória / hormonal / sensível
    • Manchas: pós-inflamatória / melasma / fotoenvelhecimento / mista
    • Poros: oleosidade / fotoenvelhecimento / desidratação / hábito (limpeza/agressão)
