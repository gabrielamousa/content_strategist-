Funciona… mas tem um jeito melhor (upgrade rápido)

Template universal para Reels de comparação: mostre o jeito comum (ok) e, em seguida, o jeito “upgrade” (melhor) — com benefício direto e repetição em blocos.

Post original: https://www.instagram.com/p/DN4A_0jAQWI/

Abrir post original link

Copia o texto do bloco “Roteiro (pronto para gravar)”.

Regra de ouro: não ataque o “comum”. Diga “funciona, mas…” e entregue um upgrade simples.

Resumo

O que é + por que retém
  • Mecânica: comparação rápida Comum vs Upgrade.
  • Gatilho: a virada do “MAS” cria curiosidade e mantém atenção.
  • Valor: várias ideias em poucos segundos (sensação de abundância).
  • Aplicação: serve para qualquer tema (processos, ferramentas, hábitos, design, conteúdo, vendas, estudo, treino).

Estrutura

15–25s
  1. Hook (1–2s): “Isso funciona… mas isso funciona melhor.”
  2. Promessa (1s): “Trocas pequenas que mudam o resultado.”
  3. Blocos (5–7x): Comum → “MAS” → Upgrade → Benefício (2–3 palavras).
  4. Fecho (2s): CTA de salvar + comentar um “insumo”.

Ritmo: frases curtas, 1 ideia por frase, cortes no “MAS”.

Quantidade: 5–7 comparações = sensação de “lista premium”.

Roteiro (pronto para gravar)

Template universal

Preencha os colchetes conforme seu tema. Mantenha cada bloco em 1 tomada para facilitar os cortes.

HOOK (1–2s) “Isso aqui funciona… mas isso aqui funciona melhor.” PROMESSA (1s) “São trocas pequenas que deixam [RESULTADO DESEJADO] sem complicar.” BLOCO 1 “[JEITO COMUM 1] é bom pra [BENEFÍCIO BÁSICO]… MAS [JEITO UPGRADE 1] fica [EFEITO 1], [EFEITO 2], [EFEITO 3].” BLOCO 2 “[JEITO COMUM 2] funciona e é [ELOGIO CURTO]… MAS [JEITO UPGRADE 2] deixa [EFEITO 1], [EFEITO 2], [EFEITO 3].” BLOCO 3 “[JEITO COMUM 3] é o seguro… MAS [JEITO UPGRADE 3] te dá [EFEITO 1], [EFEITO 2], [EFEITO 3].” BLOCO 4 “[JEITO COMUM 4] é ok quando [CONTEXTO]… MAS [JEITO UPGRADE 4] fica [EFEITO 1], [EFEITO 2], [EFEITO 3].” BLOCO 5 “[JEITO COMUM 5] é ‘o clássico’… MAS [JEITO UPGRADE 5] entrega [EFEITO 1], [EFEITO 2], [EFEITO 3].” (OPCIONAL) BLOCO 6–7 Repita o padrão com variações. FECHO + CTA (2s) “Quer que eu faça isso no seu caso? Comenta ‘UPGRADE’ + [INSUMO: tema/objetivo/nível]. E salva pra usar depois.”

Elementos visuais

Edição + tela
  • Tela dividida (opcional): esquerda “COMUM”, direita “UPGRADE”.
  • Texto na tela sempre acompanhando a fala (6–8 palavras por tela).
  • Corte no “MAS”: jump cut + zoom leve para marcar a virada.
  • SFX sutil no “MAS” (pop/woosh leve).
  • B-roll: exemplo do comum vs exemplo do upgrade (antes/depois, tela, gesto, item).
  • Fundo limpo: use cenário neutro para o texto/itens aparecerem.

Copy e ganchos

Frases prontas

Hooks (1–2s)

  • “Isso funciona… mas tem um jeito melhor.”
  • “O comum resolve. O estratégico eleva.”
  • “Você não precisa mudar tudo: só mudar o par.”
  • “O erro não é fazer X. É fazer X com Y.”

Efeitos (escolha 3)

  • mais claro / mais direto / mais rápido
  • mais profissional / mais confiável
  • mais moderno / mais limpo
  • mais consistente / mais previsível
  • menos retrabalho / menos ruído

Modelo de texto na tela

  • “Funciona: [COMUM]”
  • “MAS…”
  • “Melhor: [UPGRADE]”
  • “Efeito: [3 palavras]”

CTA

Escolha 1
  • “Comenta UPGRADE + [seu objetivo] que eu te mando uma versão melhor.”
  • “Salva pra usar quando você for fazer [tarefa].”
  • “Qual você vai testar hoje? Comenta 1, 2, 3…”
  • “Me diz seu [insumo] (ex.: ferramenta, etapa, nível, prazo) que eu sugiro o ‘par’ ideal.”

Dica: peça um insumo fácil de responder (1 palavra). Isso aumenta comentário e te dá pauta para continuação.

Checklist de criação

Do zero ao post
  1. Defina o resultado: “deixar [processo/rotina/conteúdo] mais ____”.
  2. Liste 5–7 jeitos comuns que a audiência já faz (sem julgar).
  3. Para cada um, crie 1 upgrade simples (troca pequena, grande efeito).
  4. Escolha 3 efeitos fixos (ex.: “mais claro, mais rápido, mais profissional”).
  5. Escreva 5–7 blocos no padrão: “Funciona… MAS… fica [3 efeitos]”.
  6. Grave em pé (9:16), 1 bloco por tomada, olhando pra câmera.
  7. Edite com cortes no “MAS”, texto na tela, e (opcional) tela dividida.
  8. Escolha título/capa: “O jeito comum vs o jeito melhor de [tema]”.
  9. Inclua CTA: salvar + comentar UPGRADE + insumo.
  10. Publique e responda comentários com 1 upgrade extra (vira continuação).

Variações

Reaproveite o DNA

Variação A — “3 níveis”

  • Comum (nível 1) → Melhor (nível 2) → Elite (nível 3).
  • Use: “ok / bom / excelente” com 1 frase cada.

Variação B — “Antes / Depois”

  • Mostre na prática o upgrade (tela, cena, resultado).
  • O texto na tela vira: “Antes: ___ | Depois: ___”.

Variação C — “Erro não é X, é X com Y”

  • Troque o “funciona, mas…” por “o problema é a combinação”.
  • Boa para temas com confusão comum (ferramentas, etapas, mensagens).

Variação D — “Checklist de upgrades”

  • Mesma lógica, porém em formato de lista: “Se você faz X, testa Y”.
  • Final: “Quer a versão pro seu caso? Comenta [insumo]”.

UX note: se quiser aumentar retenção, coloque o melhor upgrade no bloco 3 ou 4 (meio do vídeo) e deixe um “extra” para o final.
